# CLAUDE.md — PDFSign

A small, native macOS app that applies a **visible digital signature** to a PDF using a
certificate from the **Keychain**. The private key never leaves the Keychain: PoDoFo builds
the PDF/CMS container and delegates the raw signature to `SecKeyCreateSignature`.

Read this file first, then `README.md` for the user-facing overview.

## Project structure

```
PDFSign/                      Swift + Objective-C++ app source
  PDFSignApp.swift            @main App entry; WindowGroup, min window size
  AppModel.swift              @Observable state machine (Phase: empty/editing/signing/done/failed)
  ContentView.swift           SwiftUI UI; native title-bar toolbar (Open, Draw, cert Picker, Sign & Save)
  Models.swift                SigningIdentity, SignatureBox
  KeychainService.swift       Lists kSecClassIdentity items; common-name labels
  SignatureStore.swift        Persists the user's signature image (PNG in Application Support)
  SignatureCanvas.swift       Trackpad/mouse signature pad; renders cropped transparent PNG
  AppearanceEditor.swift      Toolbar popover: signature image, date toggle, custom text, stamp preview
  PDFPreview.swift            NSViewRepresentable PDFView + drag-to-place overlay;
                              StampAnnotation renders a live stamp preview in the placement box;
                              box is resizable (8 handles) and movable via mouse-drag sessions
  SigningEngine/
    PDFSigningEngine.h        C++-free ObjC interface (imports cleanly into Swift)
    PDFSigningEngine.mm       ObjC++ core: PoDoFo signing + SecKeyCreateSignature callback
    PDFSign-Bridging-Header.h Swift ↔ ObjC bridge

scripts/build-podofo.sh       One-time: builds a STATIC PoDoFo into vendor/ (git-ignored)
vendor/podofo/                Built artifacts: include/ + lib/libpodofo_bundle.a (git-ignored)
project.yml                   XcodeGen project definition (source of truth for the Xcode project)
PDFSign.xcodeproj/            Generated by `xcodegen generate` (git-ignored)
build/                        xcodebuild output (git-ignored)
dist/                         Release/notarization artifacts (git-ignored)
```

The Xcode project is **generated** — never hand-edit `PDFSign.xcodeproj`. Change `project.yml`
and run `xcodegen generate`.

## Architecture notes

- **Key never leaves the Keychain.** PoDoFo gets only the X.509 cert (DER). The actual
  signing happens in a `PdfSignerCmsParams.SigningService` callback wired to
  `SecKeyCreateSignature` (RSA PKCS#1 v1.5 SHA-256, or ECDSA X9.62 SHA-256 depending on key type).
- **PoDoFo is statically linked.** `scripts/build-podofo.sh` builds PoDoFo + its deps
  (OpenSSL, FreeType, Fontconfig, libpng/tiff/jpeg, brotli, lzma, zstd, gettext) and merges
  them with `libtool -static` into `vendor/podofo/lib/libpodofo_bundle.a`. The app links that
  archive by full path; only system libs (libxml2, z, bz2, expat, iconv) link dynamically via
  the SDK. Result: **no `/opt/homebrew` runtime dependency**, no embedded dylibs to sign.
- **Output format:** PAdES-B (ETSI.CAdES, detached), SHA-256. Validates in Preview, Acrobat, `pdfsig`.
- **Stamp appearance** is customizable (Appearance toolbar popover): a drawn/imported signature
  image replaces the default seal badge, plus optional date line and free-text line. Settings
  persist in UserDefaults; the image as `~/Library/Application Support/PDFSign/signature.png`.
  The engine takes them as `signatureImagePNG` / `includeDate` / `customText`.

## Build & run (dev)

```bash
brew install xcodegen cmake
./scripts/build-podofo.sh          # one-time (and after bumping PODOFO_VERSION)
xcodegen generate
open PDFSign.xcodeproj              # or: xcodebuild -scheme PDFSign -configuration Debug build
```

Debug builds are **ad-hoc signed** (`CODE_SIGN_IDENTITY = "-"`, no Hardened Runtime) for a
frictionless dev loop. Release builds are Developer-ID signed + Hardened Runtime (see below).

## Distribution: signing & notarization

Notarization is done with **[`asc`](https://github.com/aaronsky/asc)** — an unofficial App
Store Connect CLI that talks to Apple's Notary API directly (no `xcrun notarytool` needed).
Auth is an App Store Connect API key stored in the keychain; check it with `asc doctor`
(default profile must show OK). `asc` is assumed already logged in.

Signing config lives in `project.yml` per build configuration:
- **Release** config signs with `Developer ID Application` (team `286DN3SPR7`),
  `ENABLE_HARDENED_RUNTIME = YES`, and a secure timestamp (`OTHER_CODE_SIGN_FLAGS = --timestamp`).
- No entitlements file is needed: the app is not sandboxed and reads the user's login keychain,
  which Hardened Runtime permits without special entitlements. Everything is statically linked,
  so there are no nested dylibs and no library-validation exceptions.

End-to-end release (script: `scripts/notarize.sh`):

```bash
./scripts/notarize.sh              # build Release → zip → asc notarization submit --wait → staple → verify
```

Or manually:

```bash
xcodegen generate
xcodebuild -scheme PDFSign -configuration Release -derivedDataPath build clean build
APP="build/Build/Products/Release/PDFSign.app"
ditto -c -k --keepParent "$APP" dist/PDFSign.zip
asc notarization submit --file dist/PDFSign.zip --wait        # uploads, polls Apple Notary
xcrun stapler staple "$APP"                                   # attach the ticket to the .app
spctl -a -vvv -t exec "$APP"                                  # expect: accepted, source=Notarized Developer ID
```

Why staple: it embeds the notarization ticket in the bundle so Gatekeeper accepts it offline.
Re-zip the **stapled** `.app` for the artifact you actually ship.

### Release checklist (e.g. 0.1 → 0.2)

1. Commit the feature work.
2. Bump `MARKETING_VERSION` in `project.yml`; commit as `Bump version to X.Y`.
3. `./scripts/notarize.sh` → verified, stapled `dist/PDFSign.zip`.
4. `cp dist/PDFSign.zip dist/PDFSign-X.Y.zip` — versioned artifact convention.
5. `git tag -a vX.Y -m "PDFSign X.Y — …" && git push origin main vX.Y`
6. `gh release create vX.Y dist/PDFSign-X.Y.zip --title "PDFSign X.Y" --notes "…"`
